Methodology

What counts. A run counts as working if it starts in the browser and moves, even if it looks more like a pillar than a giraffe. The quality of the walk was not rated. For the other runs, the card states the reason.

Tokens. “New input” and “output” were actually computed; “cached” is the conversation history re-read with every request. Reasoning tokens count as output.

Thinking. What pi and OpenCode sent to the model about thinking was measured: each run was started again with the same harness version and the configuration of the test day against a server that only records the requests. In 75 of the 84 local runs no thinking setting was sent, so the model's default applied. 71 of these runs still contain thinking text; only the four of the two Mistral models do not. OpenCode never sent a level. pi always shows a level internally but only passed it on where the model configuration said so. The character count is the thinking text the model emitted during the run. For the cloud runs, neither harness sent a thinking setting to OpenRouter; the card shows the reasoning tokens OpenRouter billed instead.

OpenRouter cost (theoretical). For models that ran locally: what the same tokens would have cost for the same model via OpenRouter, at list prices as of November 8, 2026: new input at the input price, cached at the cache price (or the input price if none is listed), output at the output price. There the models usually run at higher precision than the quantizations tested here. OpenRouter does not offer abliterated variants and many small models.

OpenRouter cost (real). For the cloud runs: what OpenRouter actually charged. All requests went through a small local proxy that asked OpenRouter for the cheapest provider of each model and recorded the cost OpenRouter reported for every request. Where a run needed a second try, both tries are included. Runs were capped at $5, except for the three frontier models Claude Opus 5.5, GPT-6 Astra and Gemini 4 Argon. All cloud runs together cost $64.32, including discarded attempts.

Output limit. pi and OpenCode allowed up to 32,768 output tokens per response. Three runs were cut off at that limit: Claude Opus 5.5 and Gemini 4 Argon in the cloud before they had written a page, MiniMax M3 locally in the middle of its work, each with pi. They were repeated with a higher limit; the card says so. The first attempts are archived and do not count.

Models. The release date is when the original model was created on Hugging Face. Checksums are the SHA256 values Hugging Face lists for the GGUF files. All runs used llama.cpp, almost all on a Mac Studio M5 Ultra with 256 GB. Only the two qwen3.8-27b runs marked “Windows PC” ran on a second machine. The local runs date from November 4 to 9, 2026, the cloud runs from November 8 and 9. For cloud models, the release date is when the model appeared on OpenRouter. Two cloud models could not be tested: Crouton Alpha is not offered in our region, and the only provider of Muse Spark 1.3 Contributor may use requests for training, which our OpenRouter account excludes. If a run was repeated after a server change, only the new attempt counts.

The giraffes are exactly as the models wrote them; some load Three.js from a CDN. The stills were rendered in software.

Looks. Each working giraffe was rated from 1 to 5 by Claude, the AI model that also built this page, from its still image: 1 not recognizable as a giraffe, 2 rough giraffe shape with major errors, 3 clearly a giraffe with visible errors, 4 good giraffe, 5 detailed and convincing. The gait is not rated. It is a first impression, not a jury verdict.

Memory. The memory need is the size of the model files plus 10 % for context. “Fits in X GB” compares against it. On a Mac, the GPU may only use part of the unified memory by default, so leave some headroom.

Speed. Output tokens divided by coding time. It includes prompt processing and the time the tools ran, so it is lower than the pure generation speed.
