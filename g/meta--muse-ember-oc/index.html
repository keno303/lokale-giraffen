🦒 Walking Giraffe

A procedural giraffe (no model files) walking through a savanna. Pacing gait, neck bob, tail swish, ear flicks, blinking and breathing are all animated in code. Textures are generated on a canvas at runtime — so this single file works offline except for the Three.js CDN.

Drag to orbit · Scroll / pinch to zoom · Right-drag to pan (hold Shift while dragging) · Space pause
