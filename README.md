# Giraffe Benchmark / Giraffen-Benchmark

189 runs of a benchmark of language models with the harnesses pi and OpenCode, 135 of them with a working Three.js giraffe.
The files under `g/` are exactly as the models wrote them. The overview is `index.html` (English) and `de.html` (German),
the methodology `methodology.html` and `methodik.html`.
