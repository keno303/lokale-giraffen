# Giraffe Benchmark / Giraffen-Benchmark

239 runs of a benchmark of language models with the harnesses pi and OpenCode, 177 of them with a working Three.js giraffe.
The files under `g/` are exactly as the models wrote them. The overview is `index.html` (English) and `de.html` (German),
the methodology `methodology.html` and `methodik.html`, the Qwen3.8-27B quant comparison `quants.html` and `quant-vergleich.html`.
